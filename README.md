# Snake and Ladder Game

A Snake and Ladder game developed in **C** for two players.

The game provides a visual representation of the Snake and Ladder board using a graphics library. Players take turns rolling the dice and moving their tokens across the board.

## Features

- Two-player game
- Graphical representation of the game board
- Dice rolling
- Player movement
- Snakes and ladders
- Turn-based gameplay
- displays or highlights player positions
- Winner detection

## Technologies Used

- **Language:** C
- **Graphics Library:** raylib.h , graphics.h , stdlib.h

## How to Play

1. Start the game.
2. Player 1 rolls the dice.
3. The player moves according to the dice value.
4. Player 2 takes their turn.
5. If a player lands on a ladder, they move up.
6. If a player lands on a snake, they move down.
7. The first player to reach the final position wins.

## Graphics

The game uses a graphics library to create a visual representation of:

- Snake and Ladder board
- Snakes
- Ladders
- Player tokens
- Dice
- Player positions
